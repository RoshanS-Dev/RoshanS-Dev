## Featured Projects

### 1. PackSure – Legal Metrology Compliance System

**Smart India Hackathon | SIH26034**

Technologies: Python · Flask · RapidOCR · OpenCV · React · TypeScript · MySQL

- Developed an OCR-based system to extract package-label declarations.
- Validates extracted declarations against Legal Metrology (Packaged Commodities) Rules, 2011.
- Improved OCR confidence from approximately 52% to 95% using RapidOCR and OpenCV preprocessing.
- Implemented PDF compliance reports and an officer dashboard.
- Developed a SHA-256 hash-chained, tamper-evident audit trail.
